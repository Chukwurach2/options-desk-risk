# Options Desk Risk

This repository contains python implementations of core derivatives pricing, hedging,
and risk concepts inspired by *Options, Futures, and Other Derivatives* (John C. Hull),
developed from the perspective of a trading desk risk manager.

The focus is on:
- Market structure and mechanics (exchange-traded vs OTC markets, clearing, margining, settlement)
- Contract-level behavior (forwards, futures, options; obligations vs rights; payoff structures)
- Pricing and sensitivity analysis as the text progresses (forwards, options, greeks)
- Hedging mechanics, P&L attribution, and behavior under stress scenarios
- Building reusable, tested risk analytics rather than one-off scripts
